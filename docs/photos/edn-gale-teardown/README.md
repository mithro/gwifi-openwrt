# EDN Google Wifi (gale) teardown — PCB photos

PCB photos of the first-generation Google Wifi (gale, AC-1304) mainboard and
Ethernet/power daughterboard, from the EDN teardown article:

- Source: <https://www.edn.com/teardown-prying-open-google-wifi/>
  ("Teardown: Prying open Google Wifi", Brian Dipert, EDN)
- Fetched: 2026-07-26
- Copyright remains with EDN/AspenCore; kept here as reference material for
  hardware work on this project.

These are the original full-resolution uploads (1400 px wide — verified to be
the largest size EDN serves; upscale requests return the same file).
